# PIXLLM

PIXLLM은 사용자가 로컬 작업공간을 선택하고 질문하는 데스크톱 앱입니다. 모델은 선택된 작업공간을 1차 근거로 보고, 엔진 API 설명이나 활용법이 필요할 때 백엔드 엔진 소스 조회 결과를 함께 참고합니다.

질문 실행 결과는 최종 답변만 남기지 않고, 어떤 도구를 호출했는지, 어떤 파일과 줄 범위를 확인했는지, 파일을 수정했다면 어떤 차이가 생겼는지까지 같은 실행 로그에 남깁니다.

## 실행 구성

| 구성 | 역할 |
| --- | --- |
| 데스크톱 앱 | 작업공간 선택, 질문 입력, 실행 로그 표시, 세션 저장 |
| 백엔드 API | 회사 엔진 소스 개요, 검색, 읽기, 타입 관계, 사용처 조회 |
| 모델 서버 | OpenAI 호환 채팅 완료 API 제공 |
| 사용자 작업공간 | 분석과 수정의 대상 |

## 사용 흐름

1. 백엔드 API를 실행합니다.
2. 데스크톱 앱을 실행합니다.
3. 로컬 작업공간을 선택합니다.
4. 연결 설정에서 백엔드 API 주소, 모델 서버 주소, 모델 이름을 확인합니다.
5. 질문을 입력합니다.
6. 필요하면 `엔진 관련 질문`을 켜서 엔진 소스 참고 도구를 함께 사용합니다.
7. 실행 로그와 최종 답변을 확인합니다.

예시 질문:

- `이 오류 메시지가 어디서 만들어지는지 찾아줘`
- `이 화면의 submit 이후 흐름을 추적해줘`
- `이 기능을 수정하려면 어떤 파일을 먼저 봐야 하는지 알려줘`
- `NXImageView를 써서 이미지를 로드하고 보여주는 흐름을 설명해줘`

## 빠른 시작

백엔드 실행:

```bash
cd backend
cp .env.compose.example .env
docker compose up -d --build
```

헬스 체크:

```bash
curl http://127.0.0.1:8000/api/v1/health
```

데스크톱 실행:

```bash
cd desktop
npm install
npm run dev
```

포터블 빌드:

```bash
cd desktop
npm install
npm run dist:portable
```

생성 파일:

- `desktop/release/PIXLLM Desktop-0.1.0-portable.exe`

## 주요 설정

| 설정 | 기본값 |
| --- | --- |
| 백엔드 API 주소 | `http://192.168.2.238:8000/api` |
| 모델 서버 주소 | `http://192.168.2.212:8000/v1` |
| 모델 이름 | `Qwen/Qwen3.6-27B` |

엔진 원본 소스 경로와 색인 저장 경로는 데스크톱 설정이 아니라 백엔드 환경값으로 관리합니다.
